# 首版界面设计与实现计划

日期：2026-09-11。按 [产品需求文档](产品需求文档.md) 实现；“知行小课”为工作名称。

## 视觉方向

将阅读与实践并排放置，保留纸面阅读的安静感。记忆点是点一下右侧依据，左侧原文随即定位高亮；直接 AI 的主按钮始终可见，不让用户先填写表单。

色彩：画布 `#F3F6FB`、正文纸面 `#FFFFFF`、墨色 `#202E43`、操作蓝 `#2459E0`、分隔线 `#DBE2EE`、引文高亮 `#FFF1BF`。颜色分别承担背景、文字、操作和证据定位，不制作装饰性渐变。

中文标题使用本机可用宋体系列（思源宋体 / Noto Serif CJK SC / 宋体），正文与控件使用微软雅黑或苹方。字号按页面标题 36、内容标题 25、区域标题 21、正文 16、辅助信息 13 设置，正文行高约 1.8。界面不依赖在线字体下载。

## 布局选择

方案 A：逐步向导，每步只显示一项任务。它容易让“先复述”再次成为默认门槛，而且核对引用时需来回切换。

方案 B：双栏阅读工作台，选题放在可搜索的内容抽屉。采用 B；桌面左右对照，手机上下排列。正文和结果左对齐，只有主页面标题区留足呼吸空间。

```text
品牌 / 阅读工作台                         使用说明
读懂一点，往前一步。                     换一篇内容
┌ 原文片段 ─────────────────┬ 学习区 ──────────────┐
│ 真实标题、作者、可读范围     │ AI 帮我读懂 / 自己复述 │
│                            │ 讲解与适用条件        │
│ 正文 + 可定位高亮           │ 依据按钮              │
│                            │ 可修改行动 + 导出     │
└────────────────────────────┴─────────────────────┘
```

对照需求复核：去掉通用看板式数据卡、理解得分和固定示例结果；未生成时明确说明将获得什么，网络失败显示重试；保留真实作者和内容片段说明。桌面先展开适量原文，可继续阅读全部当前片段，点击引用也会自动展开定位。

## 交互与工程选择

- 首版沿用 Node 24，后端使用内置 HTTP / fetch，前端使用原生 ES modules，无构建步骤和第三方前端运行依赖。
- 文章与学习路径各自保存本页内的草稿与结果；切换中取消旧请求，防止旧内容覆盖新文章。
- 直接 AI 不要求复述或确认。结果清楚区分原文、AI 讲解、AI 行动建议与用户编辑。
- 出错时保留输入；重复生成需用户主动触发；生成时可取消等待。
- 使用原生按钮、文本框和 dialog，支持键盘、可见焦点、移动布局及减少动态效果偏好。
- Markdown 导出在浏览器完成，保留生成方式、真实来源、引用和可选用户修订，不把计划标成完成。
