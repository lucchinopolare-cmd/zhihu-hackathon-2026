# 知行小课｜界面设计

本说明描述知行小课的公开界面设计原则；产品行为和内容边界见[产品需求文档](产品需求文档.md)。

## 设计意图

界面是安静的阅读工作台：原文、AI 讲解和用户文字各有明确身份，让用户能在阅读、核对与尝试之间自然移动。点击引用时，原文中的对应片段应被定位和高亮；直接讲解入口保持清晰可见，但不压迫希望先复述的用户。

## 布局

桌面端使用双栏布局：左侧为当前可读原文片段，右侧为学习区。内容选择放在可搜索的抽屉或面板中，避免占据阅读空间。

```text
品牌 / 阅读工作台                         使用说明
读懂一点，往前一步。                     换一篇内容
┌ 原文片段 ─────────────────┬ 学习区 ──────────────┐
│ 标题、作者、可读范围        │ AI 帮我读懂 / 自己复述 │
│                            │ 讲解、条件和依据       │
│ 正文 + 可定位高亮           │ 挑战、行动与导出       │
└────────────────────────────┴─────────────────────┘
```

移动端改为原文在上、学习区在下的顺序。无论屏幕大小，来源、主操作、引用和导出都应可访问；引用跳转后仍让用户看见原文与当前结果的关联。

## 内容层次与标签

结果区依次呈现核心观点、作者公开论证步骤、适用条件与依据、AI 延伸、一分钟理解挑战、继续追问和可调整的行动。自行复述路径额外显示理解核对与修订区。

视觉与文字标签区分“原文理解”“AI 延伸”和用户编辑。行动显示为“待尝试”，避免把计划误写成完成。开发演示内容应在页面和导出结果中显示其非正式来源属性。

## 颜色与字体

| 用途 | Token |
| --- | --- |
| 画布 | `#F3F6FB` |
| 阅读纸面 | `#FFFFFF` |
| 墨色 | `#202E43` |
| 操作蓝 | `#2459E0` |
| 分隔线 | `#DBE2EE` |
| 引文高亮 | `#FFF1BF` |

颜色分别服务于背景、正文、操作、分隔与证据定位，不使用装饰性渐变。中文标题优先使用本机宋体系列（思源宋体 / Noto Serif CJK SC / 宋体）；正文和控件使用微软雅黑或苹方。建议字号为：页面标题 36、内容标题 25、区域标题 21、正文 16、辅助信息 13；正文行高约 1.8。界面不依赖在线字体下载。

## 可访问交互

使用原生按钮、文本框和对话框，提供键盘操作、可见焦点和减少动态效果偏好。加载与失败状态应以清楚的文字反馈，出错时不清除用户输入。生成、追问和场景调整均由用户主动触发；切换材料时应阻止旧请求覆盖新内容。
