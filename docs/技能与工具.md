## 队友如何复用

使用支持 Skills 的 Agent，按上表固定来源安装对应目录，并保留随附许可文件。如果使用 Codex，可让内置 Skill Installer 根据仓库、路径及提交版本安装：

```text
repo: anthropics/skills
path: skills/frontend-design
ref: 41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f

repo: openai/skills
path: skills/.curated/security-best-practices
ref: 49f948faa9258a0c61caceaf225e179651397431
```

本次全局安装只发生在准备电脑；克隆仓库不会自动安装这两项。各客户端的技能目录、发现方式和触发规则按它们各自的版本说明处理。

知乎技能可从仓库入口 [SKILL.md](../vendor/zhihu-skill-0.5.3/zhihu/SKILL.md) 读取。仅阅读接口文档不需要运行其安装脚本；后续是否需要 CLI 取决于选用接口。当前知识内容 HTTP 接口已经通过独立请求读取，不以 CLI 安装为前提。

## 换 API 后还能否使用

- 同一台电脑、同一个 Codex 中切换兼容的模型 API，一般不影响本地 skill 文件；需要另行配置模型、服务地址、认证和支持的协议。
- 前端设计、安全检查这类通用说明可继续读取；模型理解和执行能力会影响效果，安装成功不等于效果相同。
- 依赖浏览器工具、MCP、某个 CLI 或专用 API 的技能，还需要对应工具和权限。更换客户端时，应重新核对工具兼容性。
- 开发用模型 API 与参赛作品的模型 API 是两套配置。知乎官方 skill 描述的是知乎接口，换生成模型不会使这些文档失效；若知乎接口本身更新，则需更新相应 skill。
