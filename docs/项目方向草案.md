# 项目方向草案：知行小课

日期：2026-09-09。仅供组队讨论，名称、需求、技术路线和分工尚未由团队确认。

**读懂一条知乎建议，试出自己的答案。**

目标用户暂定为想改善学习方法的大学生。围绕一篇知乎知识内容，让用户解释自己的理解，核对作者原意，再设计一个具体的小行动。学习卡保留原文依据、用户判断和修改过程。

## 一次体验

1. 从官方知识列表选一篇内容，展示作者、标题及实际可读范围。
2. 用户用两三句话解释“作者建议什么、适用于什么情况”，可以表示存疑或不同意。
3. AI 依据已取得的正文片段，指出准确复述、遗漏条件或扩大原意的位置，并提供可核对的引用。
4. 用户修订自己的理解，写下行动、完成标志和回顾时机，导出 Markdown 学习卡。

只评价当前文本的理解和行动是否具体，不把赞同作者作为通过标准。计划尝试不能记为已经完成。

## 已知数据约束

2026-09-09 的独立接口抽查得到 10 项内容，并非全知乎搜索或专业课程题库。两篇详情各返回 3000 字符且句尾不完整，因此首版应明确“仅基于已获取片段”。分类标签存在不匹配现象，不能直接当可靠分类。

演示可以围绕“小胜与闭合任务回路”：把笼统的“今晚复习数据结构”改成一个有完成标志的行动。这是应用情境设计，不表示接口包含数据结构教学。

## 首版范围建议

一个页面完成选内容、片段阅读、用户复述、带引用的反馈、行动表单和导出。先不加入账号、长期打卡、语音、教材上传或知识图谱，待真实试用后决定扩展。
