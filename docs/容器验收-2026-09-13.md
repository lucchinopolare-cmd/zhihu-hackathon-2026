## 5. 演示模式核心流程（容器内，端口 3102）

接口级实测（均返回 200）：

- `/api/learn`：返回核心观点、论证步骤、适用条件、AI 提醒、AI 场景，带可定位引用。
- `/api/challenge`：反馈“关键点已覆盖”，附原文逐字引用，**不评分**。
- `/api/follow-up`：材料不足时明确回答“当前材料不能直接回答这个问题”，未编造。
- `/api/personalize-action`：输入“高数期中考试，每天只有 40 分钟，卡在极限证明”后，任务/完成标志/回顾安排**三者均发生实质变化**（生成“20 分钟完成 3 道基础题并标出卡住步骤”“明晚只补 1 个前置概念”），不是给原行动加场景前缀。

- **真实模型仍未打通**：应用运行时模型额度在 9/13 开赛后返回 HTTP 403（令牌额度不足），本轮**未重试、未消耗额度**。当前一切可操作效果均来自演示模式。
- 封面与 ICON 已生成（见 `assets/`），但带“AI 生成”水印，提交前需用户确认是否可用或替换。

## 7. 接入真实模型的最小条件

1. 恢复 `gpt-6-astra` 所在 Key 的可用额度，或换一个可用的 Responses 兼容模型接口。
2. 在**部署平台 Secret** 中注入 `MODEL_API_KEY`（或 `ZHIHU_OPENAI_NEXT_API_KEY`），不得写入镜像、Git、前端或日志。
3. 设置 `ALLOWED_ORIGIN` 为唯一 HTTPS 公网来源并保持 `REQUIRE_ORIGIN=true`。
4. 配置 `GENERATION_SESSION_COOKIE_*` 或 `GENERATION_GATEWAY_TOKEN` 之一，避免生成接口被匿名滥用。
5. 用真实 HTTPS 来源发起一次受控 `/api/learn`，返回 200 且内容随输入变化，才可记为模型端到端通过。
