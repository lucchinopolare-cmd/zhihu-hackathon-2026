## 本地运行

首版使用 Node.js 24、内置 HTTP/fetch 和原生 ES modules，无第三方运行依赖。赛前演示无需配置；正式运行时复制 `.env.example` 为 `.env` 并填写后端模型配置，真实密钥不得进入 Git。正式 `start` 默认读取赛事知识接口，本机历史 `sample` 数据仅用于内部核对。公网启用生成授权时，浏览器请求通过同源 Cookie 或受信任网关注入的服务端凭证完成；不要把 Bearer 或其他静态 Token 写入 `public/app.js`。

```powershell
npm.cmd run demo
npm.cmd start
npm.cmd test
npm.cmd run probe
npm.cmd run probe -- --live
```

赛事内容列表为空或 live 服务不可用时，可运行 `npm.cmd run demo`，再打开 `http://127.0.0.1:3001/`。demo 使用仓库内两篇项目原创材料和预设回答，不需要密钥、不访问赛事内容接口或赛事模型；页面与导出卡均明确标注“非知乎正式内容”。`npm.cmd start` 才是读取正式赛事来源并连接真实模型的运行方式。

`--live` 会访问知乎赛事知识 API，只读取列表和一个内容详情。默认 probe 依赖本机 `sources/` 样本，新克隆的仓库不包含这些文件。

本地 fake-model 浏览器验收已覆盖深度讲解、自行复述、逐条带引用追问、引用定位、行动编辑、导出、错误恢复和移动布局。模拟状态在生成前和结果中明确展示。赛前用应用后端请求赛事模型两次，均约 126 秒后收到上游 502；9 月 13 日开赛后唯一一次受控真实生成请求收到上游 HTTP 403（令牌额度不足），因此不能记为真实模型端到端通过。未做公网部署或官方作品提交。仓库目前为私有协作仓库。
