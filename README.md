## 讨论草案：知行小课（尚未定题）

**读懂一条知乎建议，试出自己的答案。**

围绕一篇官方知识内容，让用户先解释自己的理解，再核对作者原意，最后设计一个可执行的小行动。学习卡保留原文依据、用户自己的判断与改写过程。

第一版先聚焦学习方法；实际知识接口当前返回 10 篇内容，不能宣传为全知乎检索，也没有专业课全库。

设计使用 Node.js 24，无第三方包安装依赖。**已按用户要求暂停：以下骨架已写入但未测试或运行，不代表可用产品。**具体状态见 [开发日志](docs/开发日志.md)。
