## 讨论草案：知行小课（尚未定题）

**读懂一条知乎建议，试出自己的答案。**

围绕一篇官方知识内容，用户可以直接让 AI 讲解，也可以先复述再核对，最后得到一个可修改的小行动建议。允许跳过复述直接生成和导出，学习卡保留原文依据并区分 AI 内容与用户文字。

候选第一版先聚焦学习方法；2026-09-09 的知识接口样本返回 10 篇内容，不能据此宣传为全知乎检索或专业课全库。

## 技术准备骨架

原有数据骨架使用 Node.js 24，无第三方包安装依赖。**2026-09-11 历史本地测试 8 项通过，离线 probe 通过；不代表可用产品。**具体记录见 [开发日志](docs/开发日志.md)。

```powershell
npm.cmd test
npm.cmd run probe
npm.cmd run probe -- --live
```

本轮需求与技能整理未重新运行这些命令。`--live` 会访问知乎赛事知识 API，只读取列表和一个内容详情；历史通过的是离线探测。默认不带 `--live` 时依赖本机 `sources/` 样本，新克隆的仓库不包含这些文件。
